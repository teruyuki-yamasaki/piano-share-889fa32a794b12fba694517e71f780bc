# Score Companion 使い方ガイド

主旋律を自分で弾く（歌う）と、伴奏がそれに合わせてついてくる練習アプリです。

## よくある質問: 右手だけ弾いて、左手の伴奏を聞きたい

練習バーの **「弾く」** を選んでください（最初からこの設定です）。

- 右手（主旋律）があなたのパート、左手（伴奏）は **自動演奏** になり、あなたの演奏に合わせて鳴ります
- 練習バーのパートの札で確認できます。「右手 **あなた**」「左手 **自動**」となっていれば OK
- 札をクリックすると、パートごとに「あなた ⇔ 自動」を切り替えられます（左手だけ・両手とも、など）
- 連弾の曲は、札が「セコンド」「プリモ」の奏者ごとにまとまります。奏者の札で両手をまとめて、手の札で片手ずつ切り替えます（最初はプリモの両手があなた）
- **「聴く」** にすると、全部のパートが自動になります。「弾く」に戻すと、さっき選んだパートに戻ります
- 伴奏の音の出し先と音量は、上のバーの機器名 → **「伴奏の音を出す先」「伴奏の音量」**

| やりたいこと | 選ぶもの |
|---|---|
| 右手を弾いて、左手は伴奏で鳴らす | 弾く（最初の状態） |
| 左手を弾いて、右手のメロディーを鳴らす | 弾く → 札で右手を「自動」、左手を「あなた」に |
| 両手とも自分で弾く（音は鳴らない） | 弾く → 札で両手を「あなた」に |
| 全部を自動で聴く | 聴く |

## 起動と終了

1. `start.command` をダブルクリック（ターミナルなら `npm start`）
2. Google Chrome で http://localhost:5173 が開きます
3. 終わるときはターミナルのウィンドウで <kbd>Ctrl</kbd>+<kbd>C</kbd>（またはウィンドウを閉じる）

> <kbd>Ctrl</kbd>+<kbd>Z</kbd> はサーバーを「一時停止」するだけで、次の起動を妨げます。もし押してしまっても、もう一度 `start.command` を開けば自動で片付けて起動し直します。

## 画面の見方

- **上のバー**: 曲の選択（マイライブラリへの追加・削除も）、再生（前の曲・再生・次の曲・リピート）、速さ、MIDI 機器（押すと機器と音の設定）、音名、鍵盤の範囲、配色、言語切り替え、使い方（このガイド）
- **練習バー**: 弾く / 聴く、進み方（待ってくれる・テンポどおり・採点）、パートごとの「あなた / 自動」、マイク、メトロノーム、カウント、くり返し
- **楽譜**: いま弾いている位置に赤いカーソル。次に弾く音符が光ります。小節をクリックするとそこへ移動
- **ピアノロールと鍵盤**: 落ちてくる帯が赤い線に届いたら弾きます。帯の長さが押さえる長さ
- **楽譜とピアノロールの境目**: 上下にドラッグすると楽譜の欄の高さを変えられます（楽譜は欄に入るよう縮みます）。ダブルクリックで自動の高さに戻ります
- **下のバー**: 小節番号、弾けた音とミスの数

## 伴奏の音色とペダル

**音色**: 上のバーの機器名 →「伴奏の音色」

- **自分の演奏と同じ**（既定）: 電子ピアノ本体で音色を選び直すと、伴奏もその音色になります。電子ピアノがボタン操作のたびに送ってくる音色の情報を、そのまま伴奏に使います。ページを開く前に選んだ音色はわからないので、本体でもう一度選び直してください
- **ピアノ・エレクトリックピアノ・チェンバロ・オルガン・ストリングス・コーラス**: 伴奏だけ別の音色にします。電子ピアノには General MIDI の音色番号で指定するので、機種によっては近い別の音色になることがあります
- 伴奏だけ別の音色にしたら自分の鍵盤の音まで変わってしまう場合は、「伴奏を送る MIDI チャンネル」を **2** にしてください
- パソコンから鳴らすときは、アプリ内蔵の音色（6 種類）で鳴ります

**ペダル**: 楽譜にペダル記号（MusicXML の Ped. 記号、MIDI ファイルのペダル情報）があれば、伴奏はそのとおりにペダルを踏みます

- 「待ってくれる」では、待っている間はペダルを踏んだまま、弾いた瞬間に踏み替えます
- 同梱の 2 曲にはペダル記号がありません（ペダルなしで弾く曲です）
- あなた自身のペダルは、電子ピアノ本体の音にそのまま効きます
- 設定の「楽譜のペダル記号どおりに、伴奏でペダルを使う」で切れます

## 進み方（3 種類）

| 進み方 | どう動くか | 向いている練習 |
|---|---|---|
| 待ってくれる | 次の音を弾くまで曲（伴奏も）が止まって待つ | 譜読み、はじめての曲 |
| テンポどおり | 曲は止まらずに進み、弾き逃しは「見逃し」になる | 本番どおりの通し練習 |
| 採点 | テンポどおりに進み、1 音ずつ採点して記録する | 仕上がりの確認、カラオケ |

「待ってくれる」では再生ボタンを押さなくても、光っている最初の音を弾けば始まります。

## 採点モード（カラオケ）

1. 「進み方」で **採点** を選ぶ
2. 再生ボタン（またはスペース）を押す。必ず 1 小節のカウントが入ります
3. 最後まで演奏すると結果が出ます。区間を「くり返し」で指定していると、その区間を 1 回通して採点します

**判定**（自分の音ごと）

| 判定 | タイミングのずれ |
|---|---|
| Perfect | 50 ms 以内 |
| Great | 100 ms 以内 |
| Good | 200 ms 以内 |
| Miss | 弾かなかった |

- 点数は 100 点満点。判定に加えて **音の長さ**（書かれた長さを押さえ続けたか）と、マイク入力では **音程のずれ**（セント）も加味します
- 間違った音を弾くと少し減点されます
- 結果には「走り気味 / 遅れ気味」の傾向、小節ごとの出来、この曲の採点の記録（自己ベストと最近の 5 回）が出ます
- 記録はこのブラウザに保存されます（曲ごと・最大 20 回）

## マイク入力（歌・アコースティック楽器）

電子ピアノがなくても、**歌** や **リコーダー・バイオリン・フルート・アコースティックピアノ** などの音で進められます。

1. 練習バーの **マイク** ボタンを押す（はじめてのときはマイクの使用を「許可」）。入力の大きさの流れと、聞き取った音がボタンの中に出ます
2. 光っている音を歌う / 吹く / 弾く。鍵盤に聴き取った音が表示されます
3. 反応が悪いときは、上のバーの機器名 → **マイクの感度** を上げる。雑音に反応するときは下げる

- 聴き取れるのは **単音（メロディー）** です。和音のパートは、どれか 1 音が合えば弾けたことにします
- **オクターブ違いも正解にする**（既定でオン）: 楽譜より 1 オクターブ低く / 高く歌っても正解になります
- 伴奏をパソコンのスピーカーで鳴らすと、その音をマイクが拾うことがあります。**ヘッドホン** か、電子ピアノからの出力がおすすめです（伴奏と同じ音を拾ったときはミスとして数えないようにしています）
- マイクの判定はわずかに遅れるため、アプリ側で補正しています

## 速さ・メトロノーム・くり返し

- **速さ**: 0.5〜2.0 倍の段階から選びます。カーソルを合わせると実際のテンポ（♩=）が出ます
- **メトロノーム**: 拍ごとにクリック音
- **カウント**: 再生前に 1 小節ぶんクリック（採点モードでは常にオン）
- **くり返し**: チェックを入れて開始・終了の小節を選ぶと、その区間をループします。楽譜の小節をクリックすると開始位置が入ります
- **リピート**（再生ボタンの右の ⟳）: 押すたびに「くり返さない（灰色）→ 全曲 → 1 曲（「1」の印）」と切り替わります
  - **全曲**: 曲が終わるたびに、曲の一覧（上の曲名の欄の順）の次の曲へ進み、最後の曲のあとは最初の曲に戻ります
  - **1 曲**: 曲の最後まで行ったら最初に戻って続けます
- **前後の曲**: 再生ボタンの左右の ⏮ / ⏭ で、曲の一覧の前後の曲へ移れます（⏮ は、曲の途中ならその曲の最初へ、頭なら前の曲へ）
- **音名**: 上のバーの「ドレミ / C D E / 音名なし」で、鍵盤と落ちてくるノートの音名表記を切り替えます
- **鍵盤**: 「曲の音域」はその曲で使う範囲だけを大きく表示（初心者向け）、「88 鍵」はピアノの全鍵盤を表示します

## 自分の楽譜を使う

画面にファイルをドラッグ & ドロップします。残しておきたい楽譜は、曲名の欄の最後の「＋ 楽譜を追加…」から入れます。

| 形式 | 補足 |
|---|---|
| MusicXML（.musicxml / .xml / .mxl） | いちばん正確。その場で開きます |
| MIDI（.mid） | その場で開きます。1 トラックだけなら、最高音を主旋律として自動で分けます |

### マイライブラリ

曲名の欄を開いて、最後の **「＋ 楽譜を追加…」** で MusicXML・MIDI を登録すると、次回からも曲の一覧に出ます。マイライブラリの曲を開いているときは、同じところの **「− 「曲名」を削除」** で消せます。

- ターミナルからまとめて追加: `npm run add -- 楽譜1.musicxml 楽譜2.mxl`
- PDF は直接は開けません。楽譜認識のツール（score-omr など）で MusicXML にしてから追加してください

## 設定（上のバーの機器名をクリック）

| 項目 | 内容 |
|---|---|
| 入力（弾く鍵盤） | どの MIDI 機器で弾くか |
| 伴奏の音を出す先 | 電子ピアノ / このパソコン / 両方 |
| MIDI 出力先 | 伴奏を送る MIDI 機器 |
| 自分の演奏もパソコンから鳴らす | 音源のない MIDI キーボード向け |
| 伴奏の音量 | 伴奏だけの音量 |
| 伴奏の音色 | 自分の演奏と同じ / ピアノ / エレピ / チェンバロ / オルガン / ストリングス / コーラス |
| 伴奏を送る MIDI チャンネル | 通常は 1。伴奏だけ別の音色にするときは 2 |
| 楽譜のペダル記号どおりに、伴奏でペダルを使う | 楽譜にペダル記号がある曲で有効 |
| 音名の表示 | ドレミ / C D E / なし |
| ノートの落ちる速さ・88 鍵表示 | 見え方の調整 |
| マイク入力 | オン / オフ、使うマイク、感度、オクターブ違いを正解にするか |

## 困ったとき

- **起動しない / ページが開かない**: ターミナルを閉じて `start.command` を開き直してください。以前のサーバーが固まっていても自動で片付けます。5173 番が別のアプリに使われているときは 5174 番以降で起動します（ターミナルに URL が出ます）
- **電子ピアノが認識されない**: Chrome で開いているか、アドレスバーの鍵アイコンで MIDI が「許可」になっているかを確認。ケーブルを挿し直すと自動で再認識します
- **伴奏の音色が変わらない**: 「伴奏の音色」が「自分の演奏と同じ」なら、電子ピアノ本体で音色を選び直す。それでも変わらなければ、伴奏の音色を直接選ぶ
- **伴奏の音が出ない**: 設定の「伴奏の音を出す先」を「このパソコンから鳴らす」にして試す。画面を一度クリックしないと音が出ないブラウザもあります
- **マイクが反応しない**: マイクボタンが点灯しているか、設定の入力レベルが動くかを確認。感度を上げる、楽器をマイクに近づける
- **マイクが伴奏や雑音に反応する**: ヘッドホンを使う、感度を下げる
